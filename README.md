# Bank Customer Churn Analysis

## Project Overview

This project analyzes customer churn behavior in a retail banking environment using SQL, Python, and Power BI. The objective is to identify key factors influencing customer attrition, uncover high-risk customer segments, and provide actionable recommendations to improve customer retention.

The analysis includes data cleaning, exploratory data analysis (EDA), customer segmentation, KPI reporting, and interactive dashboard development. Key business dimensions such as geography, age, product usage, account balance, credit score, and customer activity were evaluated to understand their impact on churn.
